# MediConnect AI

MediConnect AI is a bilingual healthcare management and AI-assisted
care-navigation platform designed for clinics and medical centers.

## Main Features

- Patient registration
- Doctor dashboard
- Appointment booking
- Electronic medical records
- Prescription history
- SMS and WhatsApp reminders
- AI symptom-information assistant
- Analytics dashboard
- Arabic and English support
- Role-based access control

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Security
- PostgreSQL
- Redis

### Frontend
- React
- TypeScript
- Material UI
- TanStack Query

### Infrastructure
- Docker
- Docker Compose
- Nginx
- GitHub Actions
